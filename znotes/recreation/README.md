# educator-ai recreation — runnable proof

A working recreation of the four ZNotes "My Teaching Toolkit" generators
(lesson-plan / rubric / sow / clarify). Structure matches the real captured
outputs 100% (see `../research/2026-10-22-recreation.md` and
`verification/`). Prompts and generated content are original; only the
interface contract is mirrored.

## Layout

- `src/lib/presets.ts` — form presets (mirrored option lists) + rubric score rule
- `src/lib/schemas.ts` — the four output TypeScript contracts
- `src/lib/fidelity.ts` — content-free real-capture anchors + validator
- `src/lib/prompts.ts` — original schema-locked prompts (server-side only)
- `src/app/api/generate/route.ts` — POST {toolType, data}; JSON extraction,
  one self-heal retry, rubric score + sow metadata post-processing
- `src/app/page.tsx` — single-page UI: tool grid → form → tabbed output → fidelity panel
- `src/components/toolkit/` — forms, renderers, fidelity panel
- `verification/` — four real API responses produced by this recreation
  (original content, generated by the app itself) with fidelity results

## Running

Drop `src/` into any Next.js 16 App Router project that has `z-ai-web-dev-sdk`
and shadcn/ui components installed (Tailwind v4). The LLM call happens only in
`src/app/api/generate/route.ts`. Fidelity validation also runs client-side
(`fidelity.ts` has no server dependencies).

## Honest limits

- Prose is GLM-generated; ZNotes runs a Claude-class backend
  (`originalUrl: "znotes-claude"`). Word-level output differs — as it does
  between ZNotes' own runs.
- Array counts/lengths are calibrated to observed profiles but not guaranteed
  identical run-to-run (non-determinism).
- ZNotes' real prompt text is server-side and unknowable; these prompts were
  engineered from scratch against the observable contract.
